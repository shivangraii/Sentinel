🛰️ Sentinel

A research agent that doesn’t just answer, it audits itself: every sentence must cite evidence, and a critic verifies each claim before the report is returned.

Open the live app Source on GitHub
Plan→ Research (KB · web · arXiv)+ Analyse (SQL · Python)→ Write with [E#] citations→ Critic verifies claims↺ Report + sources

Hybrid retrieval

Dense + BM25 fused with Reciprocal Rank Fusion, then reranked.

Self-verification

Missing or invented citations are caught deterministically; failures trigger re-research.

Human in the loop

Pause after planning to approve, edit or reject the plan.

Guardrails

Read-only SQL, restricted Python, prompt-injection filtering, run budgets.
